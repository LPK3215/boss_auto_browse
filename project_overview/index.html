关于这个项目

这是一个开源玩具。最初就是给女朋友做了一个在 BOSS 直聘上自动浏览候选人的小工具，顺手开源了。

它没有什么重大意义，使用场景也很固定——就是定时按右箭头键而已。核心只有一个 PowerShell 脚本，逻辑简单，所以项目很好维护，也不会有什么大的变动。

核心函数

Get-ForegroundProcessName L26

获取当前前台窗口对应的进程名。通过 Win32 API GetForegroundWindow + GetWindowThreadProcessId 实现。

function Get-ForegroundProcessName {
    $hwnd = [BossAutoWin32]::GetForegroundWindow()
    if ($hwnd -eq [IntPtr]::Zero) { return $null }
    $pidValue = 0
    [void][BossAutoWin32]::GetWindowThreadProcessId($hwnd, [ref]$pidValue)
    if ($pidValue -eq 0) { return $null }
    try { return (Get-Process -Id $pidValue).ProcessName } catch { return $null }
}
Get-TargetBrowserWindow L46

查找 BOSS 直聘相关的浏览器窗口。遍历 6 种浏览器进程，优先匹配标题含 BOSS/zhipin 的窗口，否则 fallback 到任意浏览器。

Activate-BrowserWindow L60

激活目标浏览器窗口到前台。ShowWindow + AppActivate，两次延迟确认（300ms + 500ms），确保焦点获取成功。

Confirm-KeySent L71

确认按键发送后焦点仍在浏览器中。检查前台进程是否在 $allowedBrowsers 列表中。

Add-Log L76

向日志列表添加一条记录。新日志插入顶部（Insert(0)），超过 200 条时从底部移除旧日志。

快速开始

环境要求

  • Windows 10/11
  • PowerShell 5.1 或更高版本（Windows 自带）
  • 任意支持的浏览器（Chrome、Edge、Firefox、Brave、Opera、Tabbit）

运行方式

推荐

双击启动

双击 run.bat 即可启动 GUI。

命令行

PowerShell 运行

powershell -ExecutionPolicy Bypass -NoProfile -File boss_auto_browse_gui.ps1

使用步骤

1

在浏览器中打开 BOSS 直聘，进入候选人/职位详情页

2

运行 run.bat 启动程序

3

设置 间隔时间（秒）和 最大次数（0 = 无限）

4

点击 Start 开始自动浏览

5

可随时点击 Pause 暂停，再次点击 Resume 恢复

6

点击 Stop 停止并重置计数

提示：需先打开一个候选人/职位详情页，右箭头键才能在候选人之间切换。

常见问题

双击 run.bat 没反应或闪退？

以管理员身份运行 PowerShell，执行 Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned，然后再双击 run.bat。

提示 "无法加载文件，因为在此系统上禁止运行脚本"

这是 PowerShell 执行策略限制。执行 Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned 解除。

程序启动了但没有自动按键？

确保：浏览器已打开且窗口没有最小化、已进入 BOSS 直聘候选人/职位详情页、点击了 Start 按钮、状态栏显示 Running。

支持哪些浏览器？

Chrome、Edge、Firefox、Brave、Opera、Tabbit。其他浏览器需在 $allowedBrowsers 数组中添加进程名。

间隔时间最小可以设多少？

可以设为小数（如 0.5 秒），但不建议低于 1 秒，否则浏览器可能来不及响应。

最大次数设为 0 是什么意思？

0 表示无限，会一直发送直到手动停止。设为正整数则发送对应次数后自动停止。

工具会修改浏览器页面内容吗？

不会。工具仅模拟键盘按键（右箭头），不注入任何 JavaScript 或修改 DOM。
